# Flow document — write your own explanation before submission

The assessment explicitly requires this document to be written in your own words. This guide is a checklist, not a completed flow document.

Explain in your own words:
1. What happens when a user opens the frontend.
2. How the search form sends origin, destination, and weight to the API.
3. How the controller validates input and calls the repository.
4. How the repository uses parameterized SQL and returns only approved rates.
5. What happens to an uploaded PDF, including file limits, text extraction, and staging.
6. Why image-only PDFs need OCR and why candidates are not automatically approved.
7. How natural-language parsing works with optional LLM configuration and regex fallback.
8. How the normalized tables relate to one another.
9. Current limitations and what you would build next.
10. How you ran and tested the project locally.
